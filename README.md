# آیین‌نامه مرکز رشد واحدهای فناور علوم انسانی اسلامی

ارائه HTML انیمیشنی ۳۲ اسلایدی از «آیین‌نامه مرکز رشد واحدهای فناور علوم انسانی اسلامی جامعه‌المصطفی العالمیه» — معاونت پژوهش، مهر ۱۴۰۵.

> ⚠️ متن اسلایدها عیناً و بدون تغییر از سند رسمی برداشت شده است (فقط ساختاردهی بصری انجام شده است).

## ✨ ویژگی‌ها

- **۳۲ اسلاید** سازمانی با چیدمان‌های متنوع (جلد، فهرست، فصل‌بندی، جریان‌کاری، کارت‌های آماری و…)
- **تم سورمه‌ای تیره + طلایی** مطابق هویت سازمانی
- **کاملاً راست‌به‌چپ (RTL)** با فونت فارسی Vazirmatn
- **انیمیشن‌های CSS خالص** — بدون وابستگی به JS برای نمایش محتوا (ورود پله‌ای، بلور، حرکت اسلاید)
- جلوه‌های تزئینی Magic UI: شبکه متحرک، شهاب‌ها، موج (Ripple)، حاشیه نورانی، Marquee و…
- ناوبری کامل: کیبورد، لمسی (Swipe)، پرش با hash و دکمه‌ها
- واکنش‌گرا — از موبایل تا نمایشگرهای بزرگ (نگاه کنید به [📱 ریسپانسیو](#-ریسپانسیو))

## 📱 ریسپانسیو

نسبت **۱۶:۹ در همهٔ اندازه‌ها ثابت** می‌ماند تا چیدمان اسلایدها (که با واحد `cqw` مقیاس می‌شود) هرگز نشکند و متن بریده یا سرریز نشود:

| حالت | رفتار |
|---|---|
| نمایشگر/تبلت افقی | کادر ۱۶:۹ بزرگ‌ترین اندازه‌ای که در صفحه جا شود |
| موبایل افقی | نوار بالایی حذف می‌شود تا حداکثر فضا برای اسلاید آزاد شود |
| موبایل عمودی | کل صحنه ۹۰ درجه می‌چرخد؛ با چرخاندن گوشی، اسلاید تمام‌صفحه و بدون حاشیه دیده می‌شود (راهنمای چرخش هم نمایش داده می‌شود) |
| تبلت عمودی | کادر ۱۶:۹ در مرکز صفحه بدون تغییر نسبت |


## 🚀 اجرا

```bash
bun install
bun run dev
```

سپس `http://localhost:3000` را باز کنید.

## ⌨️ میانبرهای ارائه

| کلید | عملکرد |
|---|---|
| `←` / `Space` / `PageDown` | اسلاید بعدی (راست‌به‌چپ) |
| `→` / `PageUp` | اسلاید قبلی |
| `Home` / `End` | اول / آخر |
| `F` | تمام‌صفحه |
| `P` | پخش خودکار (هر اسلاید ۹ ثانیه) |
| `#5` در آدرس | پرش مستقیم به اسلاید ۵ |

## 🛠 فناوری

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS 4 + shadcn/ui
- Magic UI Components (CSS-based animations)
- فونت Vazirmatn از next/font

## 📁 ساختار

```
src/
├── app/                       # صفحه اصلی و تنظیمات (RTL + فونت)
├── lib/deck/                  # لایه داده — هر اسلاید یک فایل مستقل
│   ├── types.ts               # انواع SlideData
│   ├── meta.ts                # مشخصات ارائه
│   ├── slides/01-*.ts … 32-*.ts  # متن هر اسلاید (عین سند)
│   └── index.ts               # ترتیب ارائه
└── components/
    ├── deck/
    │   ├── deck-viewer.tsx    # موتور ارائه (کیبورد، هش، اتوپلی، فول‌اسکرین)
    │   ├── slide-view.tsx     # دیسپچر: انتخاب چیدمان بر اساس kind اسلاید
    │   ├── layouts/           # ۲۲ چیدمان — هر چیدمان یک فایل مستقل
    │   ├── parts.tsx          # اجزای مشترک (کارت‌ها، سرصفحه، تبصره، چیپ)
    │   └── rich-text.tsx      # رندر متن با تأکید <b>
    └── ui/                    # کامپوننت‌های Magic UI / shadcn
```
