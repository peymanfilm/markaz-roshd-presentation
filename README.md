# آیین‌نامه مرکز رشد واحدهای فناور علوم انسانی اسلامی

ارائه HTML انیمیشنی ۳۴ اسلایدی از «آیین‌نامه مرکز رشد واحدهای فناور علوم انسانی اسلامی جامعه‌المصطفی العالمیه» — معاونت پژوهش، مهر ۱۴۰۵.

> ⚠️ متن اسلایدها عیناً و بدون تغییر از سند رسمی برداشت شده است (فقط ساختاردهی بصری انجام شده است).

## ✨ ویژگی‌ها

- **۳۴ اسلاید** سازمانی با چیدمان‌های متنوع (جلد، فهرست، فصل‌بندی، جریان‌کاری، کارت‌های آماری و…)
- **تم سورمه‌ای تیره + طلایی** مطابق هویت سازمانی
- **کاملاً راست‌به‌چپ (RTL)** با فونت فارسی Vazirmatn
- **انیمیشن‌های CSS خالص** — بدون وابستگی به JS برای نمایش محتوا (ورود پله‌ای، بلور، حرکت اسلاید)
- جلوه‌های تزئینی Magic UI: شبکه متحرک، شهاب‌ها، موج (Ripple)، حاشیه نورانی، Marquee و…
- **پس‌زمینهٔ ذرات نورانی (Particles)** در اسلایدهای فصل، همراه با کارت شیشه‌ای دور متن
- **نوار برند در پایین صفحه** — نام سازمان، معاونت و عنوان ارائه همیشه در پایین دیده می‌شود
- ناوبری کامل: کیبورد، لمسی (Swipe)، پرش با hash و دکمه‌ها
- واکنش‌گرا — از موبایل تا نمایشگرهای بزرگ (نگاه کنید به [📱 ریسپانسیو](#-ریسپانسیو))

## 📦 اجرای آفلاین بدون CMD و بدون دسترسی مدیر

کل پوشهٔ پروژه **مستقل** است: یک Node همراه در `runtime/` قرار دارد، پس هیچ نصب، اینترنت، CMD یا دسترسی Administrator لازم نیست. فقط یک فایل را دابل‌کلیک کنید:

| فایل | کار |
|---|---|
| `START-DECK.html` | خودِ ارائه در یک فایل مستقل (اسلایدها + CSS + فونت‌ها + تصاویر، همه درون‌خطی). دابل‌کلیک = باز شدن ارائه |
| `START.vbs` | اجرای نسخهٔ کامل برنامه با سرور محلی، **بی‌صدا و بدون پنجرهٔ کنسول**؛ مرورگر پیش‌فرض خودکار باز می‌شود |
| `START.cmd` | همان کار، برای وقتی که اجرای VBScript روی سیستم بسته باشد |
| `START-KIOSK.vbs` | نمایش تمام‌صفحهٔ بدون نوار ابزار مرورگر (خروج با `Esc`) |
| `README.txt` | همین راهنما به‌صورت متن ساده برای کپی روی فلش |
| `dist/presentation.pdf` | نسخهٔ چاپی پشتیبان: ۳۴ صفحهٔ ۱۶:۹ |

پوشهٔ `runtime/` (حدود ۱۱۴ مگابایت) شامل `node.exe` و نسخهٔ buildشدهٔ Next است و باید همراه پروژه کپی شود؛ `START-DECK.html` بدون آن هم کار می‌کند.

راهنمای دقیق و کارکرد کلیدها: **`README.txt`**.

### ساخت دوبارهٔ بسته

```bash
npm run build               # next build + کپی فایل‌های استاتیک (cross-platform)
npm start                   # اجرای نسخهٔ تولید روی 127.0.0.1:3210
npm run export:standalone   # dist/presentation.html
npm run release             # runtime/ + START-DECK.html
```

## 📦 ارائهٔ آفلاین (سالن جلسه — بدون اینترنت و بدون نصب)

در سالن جلسه نه اینترنت هست، نه CMD، نه دسترسی مدیر. برای همین یک **فایل HTML مستقل** ساخته می‌شود که همه‌چیز را داخل خود دارد: HTML هر ۳۴ اسلاید، CSS، فونت‌های وزیرمتن و امیری و لوگو.

| فایل | توضیح |
|---|---|
| `START-DECK.html` | **فایل اصلی ارائه** — با دوبار کلیک در هر مرورگری باز می‌شود (۳٫۴ مگابایت، در ریشهٔ پروژه) |
| `dist/presentation.html` | همان فایل، داخل پوشهٔ `dist/` (خروجی خام اسکریپت) |
| `dist/presentation.pdf` | نسخهٔ چاپی/پشتیبان — ۳۴ صفحه ۱۶:۹، برای وقتی مرورگر در دسترس نبود |

**در سالن جلسه فقط کافی است فایل `START-DECK.html` را روی فلش کپی کنید و دوبار کلیه کنید.** هیچ درخواستی به اینترنت نمی‌رود، هیچ برنامه‌ای نصب نمی‌شود و فایل روی خود سیستم اجرا می‌شود. اگر مرورگر سیستم خیلی قدیمی باشد یا فایل ناقص کپی شود، خودِ فایل پیام راهنما نشان می‌دهد و به نسخهٔ PDF ارجاع می‌دهد.

میانبرها همان میانبرهای نسخهٔ وب است: `←` / `Space` اسلاید بعد، `→` اسلاید قبل، `Home`/`End` اول/آخر، `F` تمام‌صفحه، `P` پخش خودکار. برای پرش مستقیم به یک اسلاید، نشانی را با شمارهٔ لاتین باز کنید، مثلاً `START-DECK.html#12`.

### ساخت دوبارهٔ فایل (روی سیستم خودتان)

```bash
npm run build                 # ساخت نسخهٔ تولید
npm start                     # اجرای سرور تولید روی 127.0.0.1:3210
npm run export:standalone -- --url http://127.0.0.1:3210 --out dist/presentation.html
npm run release               # ساخت بستهٔ قابل‌حمل (runtime + START-DECK.html)
```

اسکریپت `scripts/export-standalone.mjs` با مرورگر Chrome/Edge اسلایدها را رندر می‌گیرد، CSS و فونت‌ها و تصاویر را درون‌خطی می‌کند و یک فایل HTML مستقل می‌سازد. برای ساخت نسخهٔ PDF هم:

```bash
chrome --headless=new --no-pdf-header-footer --print-to-pdf=dist/presentation.pdf dist/presentation.html
```


## ⌨️ میانبرهای ارائه

| کلید | عملکرد |
|---|---|
| `←` / `Space` / `PageDown` | اسلاید بعدی (راست‌به‌چپ) |
| `→` / `PageUp` | اسلاید قبلی |
| `Home` / `End` | اول / آخر |
| `F` | تمام‌صفحه |
| `P` | پخش خودکار (هر اسلاید ۹ ثانیه) |
| `#5` در آدرس | پرش مستقیم به اسلاید ۵ |

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS 4 + shadcn/ui
- Magic UI Components (CSS-based animations)
- فونت Vazirmatn از next/font
