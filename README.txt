ارائهٔ آیین‌نامهٔ مرکز رشد — راهنمای اجرای آفلاین
================================================

این پوشه کامل و مستقل است: نه اینترنت لازم دارد، نه نصب برنامه،
نه دسترسی مدیر (Administrator) و نه کار با CMD.


اگر عجله دارید
---------------
۱) فایل  START-DECK.html  را دابل‌کلیک کنید.
   ارائه بلافاصله باز می‌شود. همه‌چیز داخل همین یک فایل است:
   ۳۴ اسلاید، فونت‌های وزیرمتن و امیری، تصاویر و تمام CSS.
   برای خروج از حالت تمام‌صفحه کلید F11 یا Esc را بزنید.


اگر نسخهٔ کامل برنامه را می‌خواهید
----------------------------------
۲) فایل  START.vbs  را دابل‌کلیک کنید.
   یک سرور محلی روی 127.0.0.1:3210 بالا می‌آید و مرورگر پیش‌فرض
   خودکار باز می‌شود. هیچ پنجرهٔ کنسولی دیده نمی‌شود و چیزی نصب نمی‌شود.
   (اگر روی آن سیستم اجرای VBScript بسته باشد، به‌جای آن START.cmd را
   دابل‌کلیک کنید؛ پنجرهٔ سیاه چند ثانیه باز می‌ماند و بعد بسته می‌شود.)

۳) برای نمایش تمام‌صفحه بدون نوار ابزار و منوی مرورگر:
   START-KIOSK.vbs را دابل‌کلیک کنید. خروج با کلید Esc.


پشتیبان چاپی
-------------
۴) dist\presentation.pdf — ۳۴ صفحه با نسبت ۱۶:۹.
   اگر مرورگر روی آن سیستم مشکل داشت، این فایل را با هر برنامهٔ PDF
   باز کنید.


نکته‌ها
-------
• کل پوشه را با هم کپی کنید؛ به‌ویژه پوشهٔ runtime (حدود ۱۱۴ مگابایت)
  که Node و نسخهٔ اجرایی برنامه را در خود دارد. بدون آن، START.vbs
  کار نمی‌کند (اما START-DECK.html بدون آن هم کار می‌کند).
• اینترنت لازم نیست: هیچ‌کدام از فایل‌ها درخواستی به اینترنت نمی‌فرستند.
• کلیدهای میانبر: ← یا Space اسلاید بعد | → اسلاید قبل | Home/End اول/آخر
  | F تمام‌صفحه | P پخش خودکار | نشانی #12 یعنی پرش به اسلاید ۱۲.
• اگر پیام «ارائه کامل بارگذاری نشد» دیدید، فایل به‌طور کامل کپی نشده
  است؛ دوباره کپی کنید.
• اگر پیام «مرورگر این سیستم برای نمایش ارائه قدیمی است» دیدید، از
  نسخهٔ PDF استفاده کنید.


ساخت دوباره (فقط روی سیستم خودتان؛ نیاز به اینترنت دارد)
----------------------------------------------------------
npm install
npm run build               ساخت نسخهٔ تولید
npm start                   اجرای نسخهٔ تولید روی 127.0.0.1:3210
npm run export:standalone   ساخت dist\presentation.html (فایل مستقل)
npm run release             ساخت بستهٔ قابل‌حمل (runtime + START-DECK.html)
